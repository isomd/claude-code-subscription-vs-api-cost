# Claude Code 订阅与 API 成本：计算公式和记录模板

![Claude Code 订阅与 API 成本：计算公式和记录模板](cover.png)

用于把编程工具的订阅支出与按量 API 费用放在相同任务标准下比较。这里提供计算方法和空白记录，未给出订阅或中转一定更便宜的结论。

## 固定单价计算

```text
任务费用 = 普通输入 Token / 1,000,000 × 输入单价
         + 输出 Token / 1,000,000 × 输出单价
         + 按实际计费口径计算的缓存及其他费用
```

普通输入和缓存量按账单口径拆开，避免重复计数。有上下文阶梯等条件时按实际规则计算。一个任务的修正、重试与返工请求一起计入。

## 明确标注的假设示例

2026-10-19，Orbis 公开目录中 Sonnet 4.6 的“Claude · 线路01”普通输入为 5.25 元/百万 Token，输出为 26.25 元/百万 Token。

假设普通输入 20,000、输出 2,000，无缓存与其他计费项：`0.02 × 5.25 + 0.002 × 26.25 = 0.1575` 元。20、200、2,000 个完全相同的假设任务分别为 3.15、31.50、315.00 元。这不是实际账单预测，实际价格应在登录后的线路与账单核对。

## 订阅侧核对

- [ ] `/status` 确认当前请求实际向谁结算。
- [ ] 月费、额外额度、适用税费和换汇成本换成相同币种。
- [ ] 两种方案能够完成同样的任务，所需功能都可用。
- [ ] 没有未经依据把套餐额度换成固定 API Token。
- [ ] 使用了一段有代表性的记录，而非一次特别便宜或昂贵的请求。
